# Docboot

**Docboot** is a fast, lightweight, zero-config documentation CLI that turns any folder of Markdown files into a production-ready static documentation website with a single command.

:::tip Quick Start
Turn your current folder into a live documentation website:
```bash
npx docboot . -o
```
:::

## Core Highlights

- **⚡ Sub-Second Builds**: Incremental compilation engine builds documentation pages in milliseconds.
- **📁 Zero Config by Default**: Point to any folder of Markdown files and get clean URLs, navigation, and breadcrumbs.
- **🔍 Local Offline Search**: Powered by MiniSearch with section-level deep linking (`Cmd + K`).
- **🎨 6 Designer Themes**: Modern developer color presets (`Zinc`, `Ocean`, `Emerald`, `Violet`, `Amber`, `Rose`).
- **📊 Built-in Mermaid Support**: Automatic dark/light theme aware diagrams.
- **🧩 Rich Primitives**: Tabs, synced tab groups, code groups, collapsible details, safe embeds, image lightboxes, and galleries.
- **🩺 Built-in Health Checks**: `docboot doctor` validates broken links, missing images, and frontmatter.
